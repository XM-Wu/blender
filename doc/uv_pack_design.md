# UV 岛打包：设计要点与现状梳理

本文整理一个 UV 岛打包（Pack Islands）算法应考虑的方面，并对照本仓库（Blender 5.3 原生实现）逐项说明已支持、部分支持和缺失的能力，作为后续改进的依据。

代码位置：

- 打包引擎：`source/blender/geometry/intern/uv_pack.cc`，接口 `source/blender/geometry/GEO_uv_pack.hh`
- 编辑器算子：`source/blender/editors/uvedit/uvedit_unwrap_ops.cc`（`UV_OT_pack_islands`、`UV_OT_average_islands_scale`）
- 几何节点：`source/blender/nodes/geometry/nodes/node_geo_uv_pack_islands.cc`
- UV Tools 面板入口：`scripts/startup/bl_ui/properties_uv_tools.py`

## 1. 目标与约束

打包问题中的各项需求性质不同，设计时应先区分：

| 类别 | 内容 | 处理方式 |
|---|---|---|
| 优化目标（软） | 贴图利用率、texel density（TD）统一、分组聚集、方向一致 | 可加权、可折中 |
| 约束（硬） | 旋转/缩放/翻转限制、堆叠、锁定岛、padding、目标区域 | 必须满足 |

其中 **利用率与 TD 统一天然冲突**：严格统一 TD 时只有一个全局缩放自由度；允许每岛独立缩放才能填得更满。算法应把二者的取舍暴露给用户，而不是隐式决定。

## 2. 应考虑的方面

### 2.1 贴图利用率

- **岛的形状表示**：包围盒（快，凹形岛浪费大）→ 凸包 → 精确形状（栅格占位或 no-fit polygon）。精确形状才能把小岛放进大岛的洞和凹口。
- **全局缩放搜索**：真正优化的是"能放下的最大缩放"，通常在缩放上做二分或割线搜索。
- **目标区域**：非正方形贴图、指定矩形区域、多 UDIM tile 分配。

### 2.2 Texel density

- 以 3D 面积 / UV 面积计算，考虑贴图宽高比修正。
- **容差**：允许 ±x% 偏差以换取利用率。
- **加权**：重要区域高密度，不可见区域低密度。
- **绝对模式**：直接指定 px/m（配合贴图分辨率），保证跨资产一致。
- 极小岛的最小尺寸限制（避免小于 1 像素）。

### 2.3 每个岛的变换限制

- 旋转：任意 / 90° 步进 / 锁定；可预先对齐到最小包围盒或 3D 方向（纹理方向敏感的材质）。
- **翻转（镜像）单独控制**：翻转改变切线空间手性，影响法线贴图。
- 缩放：锁定、不参与 TD 归一化、或给出上下限。
- 平移：锁定位置，其他岛绕开它（增量打包）。
- 这些限制应能 **按岛设置并持久保存**，而不只是一个全局开关。

### 2.4 堆叠

- 自动识别相同岛：拓扑一致 + 形状在容差内一致（允许相似变换；可选是否把镜像岛视为同组）。
- 每组只打包一个代表，副本复制代表的变换。
- 支持烘焙流程：烘焙时副本临时偏移整数 UV tile，结束后移回。
- 可按场景禁用（光照贴图不能堆叠）。

### 2.5 Padding 与像素对齐

- 间距按 **像素** 定义，与贴图分辨率关联；要让 mip N 不渗色，约需 2^N 像素间距。
- 岛与贴图边缘的边距单独设置。
- 可选对齐像素网格（光照贴图、低分辨率贴图）。

### 2.6 分组与空间局部性

- 同材质、同部件、同物体的岛聚在一起；用户可指定分组和分组的目标区域。

### 2.7 稳定性

- 确定性：相同输入相同输出。
- 小改动不应导致整体重排；已绘制贴图时应支持增量或局部重排。

### 2.8 性能

- 能处理数十万岛（扫描/摄影测量模型）。
- 时间预算可调（anytime：算得越久结果越好）、可取消、可多线程。

### 2.9 健壮性

- 零面积、自重叠、超出 0–1、极端长条岛等退化输入不应导致挂起或崩溃。

## 3. 现有实现梳理

### 3.1 流程

入口 `pack_islands()`（`uv_pack.cc`）：

1. **Merge Overlapping**：开启时，先把已经相互重叠的岛合并成一个岛（`OverlapMerger`，三角形两两相交测试，`O(n²)`），打包后把变换拷回各子岛。
2. **几何预处理** `finalize_geometry_()`：
   - 旋转允许时，先旋转到最小面积包围盒方向，并"竖起来"（`calculate_pre_rotation_`）。
   - Convex 模式下替换为凸包；Concave 模式保留原始三角形。
3. **缩放求解**：
   - 全部可缩放或全部不可缩放时，单次打包后按范围整体缩放。
   - 有 Fraction 边距，或部分岛锁定缩放时，用"括区间 + 改进割线法"搜索最大缩放（`pack_islands_margin_fraction`，最多 25 次迭代，每次都完整打包一遍）。
4. **放置** `pack_islands_scale_margin()`：
   - 排序：锁定位置的岛优先，其余按尺寸从大到小（`stable_sort`）。
   - 前 `alpaca_cutoff` 个岛（默认 1024；Fraction 且边距 > 0 时为 81）依次尝试 fast（Alpaca L 形）、optimal（Göbel 表）、`BLI_box_pack_2d`、xatlas（800×800 占位位图，精确形状），取最优；剩余岛用 Alpaca 按包围盒快速填充。
   - 旋转允许且岛数超过 cutoff 时，对已放置部分做最小包围正方形旋转（`rotate_inside_square`）。

### 3.2 能力对照

| 方面 | 现状 | 说明 |
|---|---|---|
| 形状表示 | ✅ 支持 | AABB / 凸包 / 精确形状（Concave）三种 |
| 洞与凹口利用 | ⚠️ 部分 | 只有 xatlas 路径（非 AABB 模式、前 1024/81 个岛）按三角形占位；其余岛按包围盒放置 |
| 全局缩放搜索 | ✅ 支持 | 割线法搜索；单次求值代价是一次完整打包 |
| 目标区域 | ⚠️ 部分 | 最近 UDIM、活动 UDIM、原始包围盒、自定义区域；只能打包进单个区域，不能跨多个 UDIM 分配 |
| 非正方形目标 | ⚠️ 部分 | 有 `target_aspect_y`，但排序与扫描线代码中留有 TODO，非 1 宽高比效果未充分处理 |
| TD 统一 | ⚠️ 部分 | 打包本身不做 TD 归一化，只对所有可缩放岛施加 **同一个** 缩放，因此保持输入的相对比例。归一化依赖 Unwrap（内部调用 `uv_parametrizer_average`）或单独的 Average Islands Scale |
| TD 容差 / 加权 / 绝对 px/m | ❌ 缺失 | 无 |
| 旋转限制 | ⚠️ 全局 | Any / Cardinal / Axis-aligned（含 X、Y）。注意 "Any" 实际是：预旋转到最小包围盒 + 90° 步进 + 整体最小正方形旋转，并非逐岛连续角度搜索 |
| 翻转 | ❌ 缺失 | `UVPhi::reflect` 及相关参数被注释为 TODO |
| 逐岛限制 | ⚠️ 间接 | 只能通过"含 Pin 的岛"＋一个全局 `pin_method`（锁旋转 / 锁缩放 / 锁旋转与缩放 / 全锁）。所有被 Pin 的岛共用同一规则，没有按岛的旋转模式、缩放范围 |
| 锁定岛 / 增量打包 | ⚠️ 部分 | `LOCK_ALL` 的岛作为障碍先放置；但此时 optimal 与 box_pack_2d 两个策略被跳过，只能用 fast 和 xatlas |
| 堆叠 | ⚠️ 部分 | Merge Overlapping 只合并 **已经重叠** 的岛（且要求宽高比相同）；无相似岛自动识别，也无持久的堆叠组。需先用 Copy/Paste UV 或 Copy Mirrored Faces 手动叠好 |
| 堆叠副本偏移（烘焙） | ❌ 缺失 | 无 |
| Padding | ⚠️ 部分 | Scaled / Add / Fraction 三种，单位是 UV 空间；无像素单位，无与分辨率、mip 层级关联 |
| 像素对齐 | ❌ 缺失 | 打包结果不对齐像素网格 |
| 分组 | ❌ 缺失 | 所有岛进同一个池按尺寸排序；多物体一起打包 |
| 确定性 | ✅ 支持 | 稳定排序，无随机 |
| 小改动稳定性 | ❌ 缺失 | 任意变化都可能导致整体重排 |
| 性能 | ⚠️ 部分 | 后台 wmJob，支持进度和取消；单线程；xatlas 位图分辨率固定 800，岛数受 cutoff 限制 |
| 健壮性 | ⚠️ 部分 | 有最小缩放 1e-5 与位图放大次数上限（避免 #159462 挂起）；本 fork 测试中 Any 旋转处理重叠方形岛时仍出现长时间等待，因此 UV Tools 面板默认关闭旋转 |

## 4. 主要缺口与改进方向

按对实际工作流的影响排序。

### P0

1. **逐岛约束的数据模型**
   在 `PackIsland` 上增加按岛字段（旋转模式、是否可翻转、缩放锁定或范围、分组 ID、堆叠 ID），`can_rotate_()` / `can_scale_()` / `can_translate_()` 改为读取这些字段，而不是只看 `pinned` + 全局 `pin_method`。约束以面属性（BMesh custom data 层）保存，使其持久、可在几何节点中读写。
2. **自动堆叠**
   按拓扑签名（面数、顶点数、度数序列）分桶，再按形状在相似变换（可选含镜像）下比对。每组只把代表交给打包，打包后把代表的变换复制给副本。`OverlapMerger` 已有"打包合并岛、再把变换拷回子岛"的机制，可复用。
3. **像素单位 Padding**
   新增贴图分辨率参数，边距按像素给出，内部换算成 UV 单位；可选按 mip 层级给出建议值。
4. **TD 控制**
   - 打包前可选内置 TD 归一化（替代必须先手动 Average Islands Scale）。
   - 支持目标 px/m 的绝对模式。
   - 支持 TD 容差：在统一缩放打包后，对剩余空间做逐岛放大（受容差上限约束）。

### P1

5. **翻转支持**：完成 `UVPhi::reflect` 的 TODO，受逐岛"可翻转"约束控制。
6. **分组**：同组岛聚集放置，或分配到各自的子区域。
7. **多 UDIM 分配**：岛总量超出单个 tile 时按分组或 TD 分配到多个 tile。
8. **像素对齐**：放置后把平移量对齐到像素网格（需在占位阶段预留取整余量）。
9. **增量打包**：锁定岛存在时仍能使用全部策略；提供"只把新岛放进空白处"的模式。
10. **非正方形目标**：处理排序与扫描线中关于 `target_aspect_y` 的 TODO。

### P2

11. **性能**：缩放搜索中各次求值独立，可并行尝试多个候选缩放；`bitmap_radix` 随岛数自适应；超大岛数时分层打包。
12. **Anytime 模式**：给定时间预算，用排序扰动或模拟退火持续改进，保留当前最优解。
13. **长时间等待问题**：调查 Any 旋转处理重叠方形岛时的耗时，补回归测试后再考虑把面板默认值改回开启旋转。

## 5. 评估指标与测试

建议为改进建立可量化基准，并与原生实现对比：

| 指标 | 定义 |
|---|---|
| 利用率 | 岛覆盖面积 / 目标区域面积 |
| TD 偏差 | 各岛 TD 相对中位数的最大偏差与方差 |
| 最小间距 | 打包后岛之间、岛与边缘之间实际最小距离（像素） |
| 约束违规 | 违反旋转、缩放、翻转、锁定、堆叠约束的岛数，应为 0 |
| 耗时 | 不同岛数（10、1k、100k）下的耗时 |
| 稳定性 | 扰动单个岛后，其他岛位置变化的比例 |

测试数据应覆盖：大小悬殊的岛、长条岛、带洞的环形岛、大量相同岛（堆叠）、镜像岛、含锁定岛的场景、退化岛，以及当前已知会长时间等待的重叠方形岛。测试可参照 `tests/python/bl_uv_tools.py` 的方式以后台模式运行。

## 6. Texel Pack：新增的打包策略

第 4 节的 P0、P1 项以一套独立的新策略实现，原生 `uv.pack_islands` 不做任何改动。

| 层 | 文件 |
|---|---|
| 引擎（纯几何，不依赖 BMesh） | `source/blender/geometry/GEO_uv_texel_pack.hh`、`intern/uv_texel_pack.cc` |
| 算子 | `source/blender/editors/uvedit/uvedit_texel_pack.cc`：`uv.texel_pack`、`uv.texel_pack_constraint_set/clear/select` |
| UI | UV Tools 的 **Texel Packing** 面板（`properties_uv_tools.py`），设置存于 `Scene.uv_tools_texel_pack`（`bl_operators/uv_tools.py`）；UV 编辑器侧栏的 **Texel Pack** 页（`bl_operators/uv_tools_texel_pack.py`） |
| UI 数据读取 | `Mesh.texel_pack_info()`（`rna_mesh_api.cc`），由 `ED_uvedit_texel_pack_info` 实现，只读编辑网格 |
| 测试 | `tests/python/bl_uv_texel_pack.py`（`script_uv_texel_pack`） |

### 6.1 核心思路：在纹素栅格上打包

所有计算都在单个 tile 的像素空间（`u * 宽`、`v * 高`）进行。占用图的每格是 `cell_size` 个像素：精度 Low/Medium/High 让格子边长不超过 512/1024/2048，Exact 为 1 像素一格。

- **保守栅格化**：岛的每个三角形按行裁剪，覆盖到的格子全部置位。面按扇形三角化，凹多边形的扇形覆盖范围只会更大，所以仍是保守的。
- **像素间距**：碰撞检测时，岛的掩膜向四周膨胀 `ceil(margin / cell)` 格；占用图只存未膨胀的掩膜。两岛的格子之间至少隔开 margin 个格，因此几何距离不小于 margin 像素。
- **边缘留白**：岛只能放在 `[edge, 栅格边长 - edge - 岛宽]` 范围内。
- **像素对齐**：栅格原点取 `floor(min / cell) * cell`，放置位置是整数格，所以平移量一定是整数像素。原来在像素网格上的顶点，只要保持缩放并按 90° 步进旋转，打包后仍在网格上。
- **放置**：左下优先（先比顶边高度，再比 x）。每行记录最长空闲段：某一行的空闲段比掩膜对应行的最长连续段还短时，直接跳过这一行；在可行的行里，只在关键行（掩膜最长连续段所在行）落入空闲段的列上做完整的位运算碰撞检测。同一个岛的各个候选方向并行求解，取代价最小者，平局取方向序号较小者，因此结果确定。

### 6.2 缩放与 TD

- 岛的 TD 为 `sqrt(像素面积 / 世界空间面积)`，单位 px/m。岛的缩放为 `global * factor`：
  - **Uniform**：`factor = 权重 / TD`，即所有岛的最终 TD 为 `global * 权重`。
  - **Keep Relative**：`factor = 权重`，保持岛之间原有的相对缩放。
  - **Target**：`global` 固定为给定的 px/m。
- **填满模式**（Uniform 和 Keep Relative，且没有锁定岛的 TD 可参照时）：每轮并行评估 4 个候选的 `global`，先倍增或倍减找到"能放下"和"放不下"的区间，再在区间内取几何插值点，直到上下界之比小于 1.005，或达到 16 轮。
- **TD 容差（混合缩放）**：某个岛放不下时，依次缩小到 `1 - tol/2`、`1 - tol` 倍再试；三种模式都可用。保持缩放的岛不缩小，容差大于 0 时先于其他岛放置，其他岛再缩小填进剩余空间；否则大岛先占位，保持缩放的岛可能放不下。
- **Target 模式**：当前 tile 放不下时依次放入后续 tile，最多 `max_tiles` 个；仍放不下的岛保持原样，并在报告中注明。
- **增量打包**：有锁定岛且模式为 Uniform 时，默认采用锁定岛 TD 的中位数，新岛与已有布局的 TD 一致。

### 6.3 逐岛约束（面属性，FACE 域）

| 属性 | 类型 | 值 |
|---|---|---|
| `uvpack_rotation` | INT | 0 用全局设置，1 锁定，2 90° 步进，3 自由（先转到最小包围盒，再 90° 步进） |
| `uvpack_flip` | INT | 0 用全局设置，1 禁止，2 允许 |
| `uvpack_scale` | INT | 1 = 保持当前缩放 |
| `uvpack_density` | FLOAT | TD 权重，0 或缺失视为 1 |
| `uvpack_group` | INT | 0 = 无分组 |
| `uvpack_stack` | INT | 0 自动识别，-1 不堆叠，>0 手动堆叠组 |
| `uvpack_lock` | INT | 1 = 位置锁定，作为障碍 |

岛内各面取值不一致时，整数属性取覆盖面积最大的值，密度取按面积加权的平均值，并在报告中提示。UV 编辑器侧栏的 **Texel Pack** 页（`bl_operators/uv_tools_texel_pack.py`，面板在 `properties_uv_tools.py`）用于编辑这些属性：

- **Island Constraints**：`Scene.uv_tools_island` 的属性带 get/set，读取所选面上最常见的取值，修改时调用 `uv.texel_pack_constraint_set`，作用于整个岛。场景属性的按钮会压入撤销步骤。读取结果按依赖图更新、撤销、重做缓存。
- **Groups / Stacks**：列出可见面上正在使用的 id，以及每个 id 的面数和 UV 包围框；可以选中、加入、新建（`uv_tools.texel_pack_new_id`，取已用最大值 + 1）和移出。
- **叠加显示**：`show_groups` / `show_stacks` 打开后，在 UV 编辑器中用半透明包围框圈出每个 id 的面并标注 `G<id>` / `S<id>`。颜色取主题骨骼颜色集，与列表图标一致，堆叠组的颜色相对分组错开。

约束算子在 UV 编辑器之外运行时（例如脚本），按网格面选择判断选中岛；在 UV 编辑器中运行时按 UV 选择。

侧栏和叠加显示的数据来自 `Mesh.texel_pack_info()`（C++，`ED_uvedit_texel_pack_info`），绘制时不使用 Python `bmesh`。原因：Python 首次创建 BMesh 元素时，会给 BMesh 添加指针层（`CD_BM_ELEM_PYPTR`），导致整块自定义数据重新分配；若此时正在变换 UV，变换中持有的指针就会失效并崩溃。属性也可以在属性面板或几何节点中直接编辑。

### 6.4 堆叠

1. **分桶**：按（面数、唯一 UV 数）分桶，世界空间面积相差超过 5% 的不比对；分组不同的岛不会被堆叠在一起。
2. **形状比对**：唯一 UV 点以质心为中心、按面积归一化。以最远点为锚，尝试 B 中长度相近的点作为旋转候选；开启镜像时，另外把 B 沿 x 镜像后再试一遍。最近点查询用网格哈希，误差小于容差才算匹配，且对应关系必须是一一的。
3. **拓扑校验**：映射后，B 的每个面在 A 中必须是同一组顶点。循环顺序相同表示副本保持朝向；顺序相反表示副本是镜像，只在允许镜像时接受（手动堆叠组总是允许）。对称网格的左右两半都是逆时针展开的，正是顺序相反的情况。没有这一步，一个翻转过的对称形状会被当成自身的 180° 旋转。手动堆叠组的形状容差至少为 5%。
4. **写回**：副本的每个 UV 直接取对应代表顶点的最终坐标，因此精确重叠。`stack_offset` 把副本额外移开 N 个 UDIM tile，用于烘焙；由于结果是确定的，烘焙后以 0 重新运行即可复原。
5. **手动堆叠组**：形状不一致的成员并入代表的形状一起打包，共用代表的变换。

### 6.5 分组与多 UDIM

- **Mixed**：忽略分组。
- **Cluster**：同组的岛先在该组已有包围盒的邻近窗口中搜索，窗口逐级 ×2 扩大，最后退回全图。
- **Tile per Group**：每组独占一个 tile（按组 ID 排序）；分组数超过 `max_tiles` 时报错。
- **起始 tile**：岛中心最近的 tile、活动 tile（图像的活动 tile 或 2D 光标所在 tile，在屏幕中查找图像编辑器），或指定的 UDIM 编号；后续 tile 沿 UDIM 编号递增。

### 6.6 已验证的结果

- `tests/python/bl_uv_texel_pack.py` 共 13 项，全部通过：
  - 打包结果：无重叠、间距与边缘留白、TD 统一、两次运行结果逐位相同。

### 6.7 后续

- 堆叠要求对应面的顶点一致（循环顺序相同或相反）；拓扑不同但外形相同的岛不会被堆叠，手动堆叠组中这种成员会与代表并排打包。
- 侧栏和叠加显示在每次依赖图更新后重新读取整个网格；很大的网格上开着叠加显示拖动 UV，可能会有卡顿。
- 岛数上万时，放置阶段仍是单线程逐岛进行，可以考虑分层打包或空闲矩形索引。
- 没有实现 anytime（时间预算内持续改进）和 no-fit polygon；对象级宽高比由贴图分辨率决定，忽略材质图像的宽高比。
