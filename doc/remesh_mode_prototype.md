# Remesh Mode 重拓扑原型

本分支为定制 Blender 5.3 增加了原生网格模式 REMESH。本文记录截至 `aab02d77b4a` 已实现的交互、验证范围，以及下一轮辅助线研究的起点。

## 操作流程

1. 选中源网格，从 3D 视口左上角进入 Remesh Mode。XM 键位也可以按 **5** 从轮盘选择。
2. **左键拖画**在表面建立四边面带。顶栏 **Strip Width** 以屏幕像素控制新面带宽度。拖动时预览每一排面，绿色可提交，红色表示当前形状无效。松开提交，Esc 取消。
3. **从边界向外拖**以已有边宽续带。笔尾靠近另一条边界时，橙色高亮表示可连接。提交后接缝共用顶点。
4. 单击选边，Shift 单击增减选择。选齐四边开口的边界后按 **F** 补一个四边面。更大的孔洞可先用面带分隔。
5. 用 **L** 锁定或解锁选中边，再选择需要调整的区域，按 **S** 松弛并贴回源面。锁定边的端点保持原位。
6. 从 **Remesh** 菜单执行 **Finish and Select Retopo Mesh**，回到物体模式时会选中独立低模。低模是源网格的子对象，可继续编辑或展开 UV；从低模重新进入 Remesh Mode 可以接着工作。

精确铺线时，**D** 后拖画生成边链，回到起点附近可闭合。**E** 后拖动可将选中的连续边界或环挤出一排面。D 产生的线属于低模几何。

## 实现与复测

原生模式接入对象模式枚举、上下文、工具系统和独立键位表。主要操作在 `scripts/startup/bl_operators/remesh_mode.py`，工具入口在 `scripts/startup/bl_ui/space_toolsystem_toolbar.py`。面带按笔迹长度采样，两侧顶点分别投射到源表面。边界焊接复用已有顶点，并检查绕序。预览和拓扑覆盖线使用平滑折线着色器及透明混合。

Release 构建的端到端验证在球面上完成：XM 轮盘进入模式，画两条带，连接两端，补中间的洞，锁边松弛，再退出和恢复。最终局部网格有 **9 个四边面、16 个共享顶点、12 条外边界边**，锁定点保持原位。补面目前支持单个四边开口；眼唇等邻近双层表面的吸附和角色变形仍需单独验证。

## 下一轮研究：先规划辅助线，再决定网格

TopoGun 3 的 Guide Lines 用于在参考面上保留规划线；Patch 可以生成与已有拓扑相接的区域网格。研究时分别观察辅助线的绘制、编辑、可见性，以及面片边界的定义、分段和提交。[TopoGun 官方功能说明](https://www.topogun.com/)

下一轮可用半张脸做返工测试：画眼睑和唇线，铺入脸颊，随后要求移动眼角、眼周加一圈、脸颊减一圈。记录哪些操作需要重画、哪些手工调整应当保留。辅助线是否驱动局部重新生成，待实际体验后决定。
