# XBone Rigging

Open **3D Viewport → Sidebar (N) → Rigging** in Object Mode.

- **Biped Template** and **Game Biped Template** read the bundled mGear Shifter guides. **Import Shifter Template (.sgt)** reads templates made with the supported components. Set the source up axis and scale in the importer. The presets use Y up and scale factors of 0.1 and 0.01, respectively.
- **Edit Guide** lets you place and rename joints before building. **New Custom Guide** starts with a root. In Edit Mode select the intended parent, then use **Add Guide Component** for FK joints, left or right arms, or legs. Each limb supplies three joint pivots and a bend plane.
- To keep an existing skeleton's joint names, hierarchy and rest frames, select the XBone object and choose **Create Guide from Selected XBone**. Select a wrist or ankle in Edit Mode and choose **Toggle Two-Joint IK at Active Joint**. The two ancestors form the limb. Give a straight limb a small bend toward its intended elbow or knee direction.
- **Build Rig** creates a separate XBone armature and opens Pose Mode. Bind the character mesh to the generated armature. Existing mesh modifiers still reference their original armature. **Edit Source Guide** returns to the guides. Each subsequent build produces a separate rig.
- Rotate the FK controls to pose a chain. Move the IK target to place the wrist or ankle, and move the pole to steer the elbow or knee. The limb property blends from FK at 0 to IK at 1. Use **Match IK** or **Match FK** to position the incoming controls before switching. With Auto Key enabled the operator keys the matched channels and the switch at the current frame.
- To export a rest skeleton to FBX, select the generated rig, set the armature to **Rest Position**, and enable **Selected Objects** and **Only Deform Bones** in the FBX exporter. Return to **Pose Position** for animation. Controller and solver bones have deformation disabled.

The importer preserves the bundled templates' component attachments and locator positions. It maps classic control, shoulder, spine, neck, arm, leg, foot, chain, metacarpal, mouth and eye guides to XBone joints, plus the EPIC component variants used by Game Biped. Two-joint limbs have native XBone IK. Other chains use FK. Available matching control-buffer curves are used for display, with generated widgets for the remaining controls. Maya custom steps, specialized facial solvers, reverse-foot behavior, spine splines and twist divisions are outside this version. The original mGear templates and their MIT license are bundled with the startup module.
